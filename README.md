# temple-sprint-3D
🏃‍♂️ Ready to escape the giant boulder? 🌋 Race through a thrilling 3D world, dodge deadly traps, leap over walls, battle drones, collect coins, and explore underwater biomes! ⚡ Unlock power-ups, complete missions, customize skins, and beat your high score. 💎 Your adventure starts now!

🏃 Temple Sprint 3D

Run. Dodge. Jump. Survive. ⚡

Welcome to Temple Sprint 3D, an exciting 3D endless runner game where you race through dangerous environments while escaping a giant rolling boulder!

🎮 Features

- 🌎 Immersive 3D gameplay
- 🪨 Giant boulder chase mechanics
- 🏃 Three-lane movement and smooth controls
- 🦘 Double jumps and sliding
- 🚁 Dangerous drones and falling rocks
- 🌊 Underwater biome exploration
- 🪙 Coins, gems, and power-ups
- 🏆 Missions, achievements, skins, and leaderboard
- 📱 Desktop and mobile controls

🕹️ How to Play

Desktop Controls

- ← / → or A / D: Switch lanes
- Space / ↑ / W: Jump
- ↓ / S: Slide
- P: Pause

Mobile Controls

- Swipe left/right to change lanes
- Swipe up to jump
- Swipe down to slide
- Use on-screen buttons when available

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Three.js

🚀 Getting Started

1. Download or clone this repository.
2. Open "temple_sprint_3d.html" in a modern browser.
3. Start your adventure and try to beat your high score!

🎯 Objective

Avoid obstacles, collect rewards, complete missions, and survive as long as possible while staying ahead of the boulder.
